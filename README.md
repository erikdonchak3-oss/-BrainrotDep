# BrainrotDep — підготовка до Telegram Mini App

## Що є в цьому пакеті
- `index.html` — поточна версія гри, перенесена з останнього наявного файлу BrainrotDep.
- Підключений офіційний Telegram Web Apps SDK та виклики `ready()` / `expand()`.
- `server.js` — простий Express-сервер для розміщення фронтенду.
- `render.yaml` — початкова конфігурація Render.

## Публікація на Render
1. Завантажте всі файли цієї папки в корінь приватного GitHub-репозиторію.
2. У Render виберіть New → Blueprint та під'єднайте репозиторій (або створіть Web Service із Node runtime).
3. Команди: Build `npm install`, Start `npm start`.
4. Після публікації перевірте адресу `/health` — має повернутися JSON з `ok: true`.
5. HTTPS-адресу сайту додайте в BotFather як URL Web App / Menu Button.

## Важливо: ще не реалізовано
Цей пакет розміщує поточну гру як вебсторінку, але сам по собі НЕ створює повноцінну багатокористувацьку гру. Потрібні окремі наступні кроки:
- перевірка Telegram `initData` на сервері;
- база даних для окремих профілів, балансів та інвентарів;
- серверні API для відкриття кейсів, апгрейдів, промокодів;
- адмін-доступ, прив'язаний до Telegram ID власника.

Не додавайте Telegram Bot API token, паролі або інші секрети в HTML чи GitHub. Їх потрібно буде внести в Render Environment Variables. Пароль, який раніше писали в чаті, слід замінити на новий.
